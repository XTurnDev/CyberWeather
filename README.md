# Pixel Sky

A weather site with a pixel art look. Pure HTML, CSS and JavaScript, no build step.

- `index.html`: the page
- `css/style.css`: all styling, including night mode
- `js/app.js`: weather, forecast, wind map, city search and clothing advice
- `js/icons.js`: the vector icons

Weather and city search come from [Open-Meteo](https://open-meteo.com) in the visitor's browser. No API key is needed.
Open-Meteo is free for non-commercial use, check their terms for anything else.

## Publish with GitHub Pages
1. Push these files to a public repository (keep the folder structure).
2. Settings > Pages > Deploy from a branch > `main` / `(root)` > Save.
3. After a minute the site is at `https://YOURUSERNAME.github.io/REPO/`.

GitHub Pages cannot run PHP, and this site does not need it.
